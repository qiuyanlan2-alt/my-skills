# 蒸汽朋克/史诗奇幻风 · 完整规范

适用范围："XX工厂/XX城堡"类史诗奇幻场景，如玫瑰工厂、能量爆发主题的视频素材。

## 一、风格定位

风格关键词：蒸汽朋克 + 玫瑰花海 + 水晶星盘 + 粉紫色光效 + 能量爆发

## 二、分镜结构模板

区别于童话公主风的"邀请→入场→穿越→庆典→留白"，本风格用五段式：**开场 → 推进 → 核心 → 爆发 → 结尾**

| 阶段 | 画面内容 |
|---|---|
| 开场 | 俯视全景定场（俯视城堡，花瓣飘落，深蓝星空） |
| 推进 | 镜头下降+光束穿城（能量流绕城飞舞） |
| 核心 | 特写道具（水晶球仪/星盘，发光物体在球内） |
| 爆发 | 白色光爆炸，能量冲击波向外扩散——全片视觉与音乐的最强锚点 |
| 结尾 | 史诗全景收尾（巨月/巨大天体背景，流星划过，可承接文字/标题） |

示例prompt结构参考（玫瑰工厂案例）：
- 开场：鸟瞰视角，夜晚，被花海包围的蒸汽朋克城堡，砖红色圆形塔楼，深紫蓝色星空，远处流星，低处薄雾，3D渲染，超精细，竖版9:16
- 推进：仰视角度，塔楼之间魔法能量光束螺旋飞舞，花瓣随风飘散，紫色体积光穿透建筑缝隙，竖版9:16
- 核心：近景特写，水晶星盘仪封印发光物体，金属圆环层层嵌套高速旋转，周围魔法能量缠绕闪烁，竖版9:16
- 爆发：水晶球中央白色光爆炸，冲击波四面炸裂扩散，强烈耀斑和镜头光晕，中心极亮向外渐暗，竖版9:16
- 结尾：宏大远景，城市被超巨大满月光晕笼罩，工业烟囱与花朵交错，粉色烟雾弥漫，流星划过，竖版9:16

## 三、剪映拼接方案（本风格专属模板，可直接套用）

### 3.1 时长与片段配比（总长15-20秒，竖版9:16）
开场3-3.5s / 推进3-3.5s / 核心特写3s / 爆发1.5-2s（全片最短但最关键）/ 结尾4-5s（留白最长，承载收尾情绪与标题）

### 3.2 转场选择逻辑
- 常规片段间（开场→推进、推进→核心）：柔和转场（推近变焦、旋转百叶窗/径向模糊），转场方向要呼应画面内的运动方向（如星盘旋转方向）
- 核心→爆发：用极短闪白/爆闪转场（0.15-0.2s）直接引爆，比常规转场更有冲击力，因为爆发本身已是强视觉事件，转场应"隐身"而非抢戏
- 爆发→结尾：冲击波扩散类转场，或用爆发尾帧白光直接叠化到结尾开场镜头，形成"尘埃落定，画面展开为全景"的叙事逻辑

### 3.3 特效叠加
- 爆发片段效果不够震撼时，剪映"光效"素材（白光爆闪/粒子冲击波）叠加在原视频上层，混合模式用"滤色"或"变亮"
- 全片可叠加梦幻粒子/光斑素材，混合模式"滤色"，透明度30-40%
- 调色统一压暗黑色部分保留星空深邃感，滤镜不超过2层

### 3.4 音乐卡点方案
- 音乐风格：史诗弦乐+梦幻钟琴/竖琴，参考迪士尼式奇幻配乐或游戏CG过场音乐，不用纯电子乐
- 卡点节奏：开场/推进段音乐铺垫上升 → 核心段进入蓄力（鼓点/弦乐渐强，卡点对准道具特写的光效闪烁峰值）→ 爆发段音乐最强拍必须逐帧手动对齐爆炸闪白帧（全片最重要的卡点，需人工校准，自动踩点常有误差）→ 结尾回落悠扬旋律，卡点对齐流星/灯光渐亮瞬间

## 四、原则延伸

"核心镜头用最强转场制造张力，其余保持柔和"这一原则不限于本风格，适用于任何带高潮/爆发段落的叙事结构。
