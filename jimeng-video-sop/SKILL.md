# 即梦AI视频制作流程规范

本skill封装了"AI生成庆典/奇幻类视频素材"的完整制作方法论，涵盖两大风格分支。核心价值在于：不要从零构思prompt结构或转场方案，而是先判断风格分支，再套用已验证的模板。

## 一、判断风格分支

先看用户描述的场景关键词，决定读哪个分支文档：

| 关键词特征 | 风格分支 | 参考文档 |
|---|---|---|
| 生日祝福、周岁纪念、感谢支持、公主、城堡童话、粉彩、贵族庆典 | 童话公主风/贵族庆典风 | `references/fairytale-style.md` |
| 工厂、蒸汽朋克、史诗、能量爆发、水晶星盘、机械齿轮 | 蒸汽朋克/史诗奇幻风 | `references/steampunk-style.md` |
| 用户给出全新风格（不属于以上两类） | 参考两份文档的**方法论结构**（分镜模板→prompt规范→图生视频规范→剪映方案→踩坑经验），套用同样的框架现场生成新内容，不要生硬套用已有的风格关键词 | 两份文档均可作结构参考 |

两个分支共享同一套底层规则（第二节），风格专属内容（视觉元素库、关键词、具体转场卡点方案）分别在各自的 references 文件里。

## 二、通用制作规则（两个分支都适用）

### 2.1 叙事节奏：三级推进 + 五段式分镜
无论哪种风格，标准做法是先按"开场定场 → 中段过渡/推进 → 核心主体特写 → （可选）爆发/高潮 → 收尾留白"拆出5个镜头左右，每个镜头内部遵循"远景定场→中景过渡→近景特写"的三级推进节奏。用一个动态元素（蝴蝶、光束、粒子等）作为视觉锚点串联转场。

### 2.2 Prompt 撰写基础结构
每条即梦生图 prompt 必须包含以下要素，缺一不可：
1. 构图方向（横版16:9 / 竖版9:16 + 明确比例）
2. 主体描述（材质+造型+装饰细节）
3. 环境背景（该风格的固定场景元素）
4. 动态元素（如需要，为图生视频做铺垫）
5. 光影质感关键词（见下）
6. 结尾双语对照：中文在前，English 完整给出，不要只给中文或只给英文

「3A级光影质感」关键词库（按需增减，不要全量堆叠）：
- 渲染引擎感：虚幻引擎5渲染、Octane渲染、电影级CG质感
- 光照：体积光、丁达尔效应、黄金时刻侧逆光、环境光遮蔽、全局光照
- 材质：PBR材质、次表面散射、金属高光反射、湿润反光质感
- 摄影感：浅景深虚化、电影级构图、35mm定焦镜头质感、色调分级
- 精度：8K超高清、超写实细节

**关键原则：** 关键词堆砌过多会导致prompt权重被稀释，出图发灰/过曝/糊。若遇到这类问题，优先精简到3-4个核心词（如"虚幻引擎5渲染+体积光+PBR材质+8K细节"），而非整段重堆。调色同理，滤镜不超过2层。

### 2.3 图生视频能力边界（务必先检查，避免设计不可行的效果）
- **普通图生视频**：只能做画面内已有元素的运动延伸（水流喷涌、蝴蝶振翅、花瓣飘落、镜头缓慢推进/环绕、粒子扩散），**不能凭空生成新元素**
- **首尾帧模式**：适合"渐变过渡"（角度/光影/姿态变化），**不适合"主体结构完全变化"**（如喷泉→镜框这种物体A变物体B的转场），成功率低，容易中间过程崩坏

动态描述prompt需包含：镜头运动方式、主体动态（强调"持续性"如"持续喷涌"）、前景动态元素轨迹、背景动态、若涉及爆发效果需具体描述光粒子扩散方向和连锁反应。

**用户的常用工作流：** 两张图作为首尾帧参考，生成4-6秒视频片段。这是首尾帧模式最主流的实操用法——选图时优先挑选"角度/光影/姿态渐变"关系的两张（如同一场景的远景→近景，或同一主体的暗光→亮光），避免选择结构完全不同的两张图（如喷泉特写→礼盒开启这种主体替换关系），否则中间过程容易崩坏。生成时长4-6秒足够覆盖大部分单镜头需求，超过这个时长的镜头建议拆成多段首尾帧分别生成再拼接，而不是硬拉长单次生成时长。

### 2.3.1 Seedance 2.0 / mini 图生视频 Prompt 写法（与即梦生图prompt结构不同）

如果用户用的是即梦 Seedance 2.0 或 mini 模型做图生视频，prompt写法与2.2节的生图prompt结构**不同**，不能直接套用：

- **只描述运动，不要重复描述图片里已有的静态内容**——模型已经能看到参考图，重复描述主体外观、材质、色彩会稀释运动指令的权重。错误示范："一座粉色城堡，尖顶，云朵环绕"（这些图里已经有了）；正确示范："镜头缓慢推进，云朵持续飘动，光斑闪烁"
- **只用正向约束，不用负向提示词**——Seedance不处理"no blur"这类否定句式，最好的情况是无效，最坏的情况是让模型混乱。用"sharp focus"代替"no blur"，"stable composition"代替"no shaking"
- **超过8秒的视频用分时段描述**（如"0-4秒：xxx；4-8秒：xxx"），4-6秒的短片段不需要分段，直接一段话描述运动即可
- 首尾帧模式下，prompt应先说明**不能变的部分**（脸部/主体结构/构图/色调一致），再说明**可以变的部分**（动作/镜头/光线/背景粒子），最后可加一句禁止事项，这样能降低模型跑偏改动主体结构的风险

参考写法模板（4-6秒首尾帧片段）：
"Camera slowly [pushes in / pulls back / orbits]. [主体的持续性动作，如"her hair sways gently"]. [前景/背景动态元素，如"petals drift down"]. [光线变化，如"soft light shifts subtly"]. Stable composition, cinematic."

### 2.4 高难度效果降级方案
当效果要求过于复杂（多重形态转变+文字炸裂同时叠加）时，按优先级拆分：
1. 保核心：优先保住最难实现的单一效果，其余降级
2. 分段生成：形态转变类效果拆成"过渡态图"分两段做
3. 后期兜底：AI生成不理想时改用剪映特效模板（光效粒子+文字弹入）二次叠加，比纯prompt堆砌更可控

### 2.5 剪映拼接方案设计原则
- **转场**：常规片段间用柔和转场（推近变焦、旋转百叶窗/径向模糊），核心镜头到高潮/爆发镜头用最强烈转场（闪白爆闪、冲击波扩散）制造张力，转场方向要呼应画面内的运动方向
- **特效叠加**：AI效果不够震撼时，用剪映光效素材叠加在原视频上层，混合模式用"滤色"或"变亮"，保留底层轮廓可见；全片粒子点缀透明度控制在30-40%，避免遮盖主体
- **音乐卡点**：核心/高潮片段的音乐最强拍必须与关键帧（如爆炸闪白帧）逐帧手动对齐，自动踩点常有几帧误差，不能只依赖自动识别
- **文字处理**：不要指望AI生成的画面自带文字，尤其是中文艺术字。先生成无文字装饰框架，文字用剪映模板后期单独叠加

## 三、常见踩坑与规避经验（通用）

| 问题 | 原因 | 规避方式 |
|---|---|---|
| 中文艺术字错字/笔画糊 | 笔画复杂字符AI还原率低 | 先生成无文字装饰框架，文字后期单独叠加 |
| 关键词堆砌过多导致发灰/过曝 | prompt权重被稀释 | 精简到3-4个核心质感词 |
| 首尾帧形态突变失败 | 模型不擅长"物体A变物体B" | 改用剪映转场，或拆分过渡态分段生成 |
| Seedance图生视频prompt重复描述图片静态内容 | 模型已能看到参考图，重复描述稀释运动指令权重 | 只写运动/镜头/光线变化，不写主体外观 |
| 镜面反射+复杂文字同时要求 | 镜面反射易使文字笔画变形 | 分开生成文字层与镜面层，后期合成 |
| 多重高难度效果叠加成功率低 | 单条prompt信息过载 | 按优先级拆分，核心效果优先，次要效果后期兜底 |

## 四、工具链

- 主力生成工具：即梦（Jimeng），中文语境优先，支持中英双语prompt
- 参考对标工具：Midjourney（英文prompt风格可互通）
- 后期合成工具：剪映（Jianying），用于复杂转场、艺术字图层叠加方案、特效兜底

## 五、输出时的下一步

根据第一节判断出风格分支后，读取对应的 `references/fairytale-style.md` 或 `references/steampunk-style.md` 获取该风格专属的视觉元素库、关键词、分镜表和转场卡点细节，与本文件的通用规则结合后再输出完整方案。
